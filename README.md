# ULTROAN research notes

Saved by ULTROAN every trading evening (the owner, 16 November 2026: "Send this summary every day and save this summary on
GitHub as well everyday to run the research on the saved data"). Nothing here is read by the server or by any page.

- `vp-summaries/<date>.md`: the Volume Profile day summary sent to the owner.
- `vp-summaries/<date>-<INDEX>.json`: the same day as data (levels as they grew, level events, calls, refused signals).
- `vp-summaries/<date>.png`: the day's chart.

The numbers are a replay of the page's own code (`static/vpshape.js`, `static/impulse.js`, `vpsignal.py`) on the saved session
(`sessions/<date>.json` on the `data` branch), not a recording of the screen.
